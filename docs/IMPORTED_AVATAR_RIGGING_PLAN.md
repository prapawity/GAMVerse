# Imported avatar rigging

## Phase 1

Generate a rig and looping Idle and Walk clips in the client asset loader for static GLBs with recognizable upright two-leg or four-leg geometry. Reuse the prepared model in the preview, 3D world and 2D sprite generator. Keep the uploaded GLB as the source and keep unsupported shapes usable as static avatars.

## Phase 2

For shapes that cannot be inferred confidently, add an optional editor for identifying joints and checking skin weights before accepting the rig.
